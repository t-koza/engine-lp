# 賃貸仲介会社 店舗単位 営業リスト生成ツール

フォーム営業用の「賃貸仲介会社の**店舗単位**」リストを、公式サイトを実際に巡回して
生成するパイプラインです。**正確性を最優先**し、推測でデータを作りません。取得できない
値は空欄、生存しないURLは出力しません。

## なぜこの形（コード納品）なのか — 重要

本リストの作成元セッションは **ネットワークが制限された実行環境** で起動されました。
この環境では:

| 手段 | 可否 |
| --- | --- |
| Web検索（公式URLの発見） | ✅ 可能 |
| Webページの取得（WebFetch / curl / requests） | ❌ **全サイト403で不可**（egressポリシー拒否） |

そのため当該セッションでは「全URLのHTTP200確認」「店舗詳細（住所・電話・フォームURL）抽出」
という必須要件を満たせません。仕様で禁じられた**推測補完を避ける**ため、その場で
500行のCSVを生成することはせず、**開放ネット環境で実行すれば仕様通りに完遂できる
スクレイピング+検証+出力パイプライン一式**を納品します。

シードURL（各社の公式店舗一覧URL）は2026-06時点のWeb検索で**実在確認済み**のものです
（`seeds.json` 参照）。

## 実行方法（開放ネット環境）

```bash
cd tools/store-list-scraper
pip install -r requirements.txt
python run.py                                   # 全社・優先5都府県（東京/神奈川/埼玉/千葉/大阪）
python run.py --max-stores 600                  # 600件到達で打ち切り
python run.py --only エイブル,ミニミニ           # 会社を限定
python run.py --prefectures 東京都,神奈川県      # 都道府県を限定
```

プロキシ環境では `REQUESTS_CA_BUNDLE` / `HTTPS_PROXY` を環境変数で設定すれば自動利用します。

## 出力（`output/`）

| ファイル | 内容 |
| --- | --- |
| `stores.csv` | 店舗リスト（UTF-8 BOM付。Excelで文字化けしない） |
| `stores.xlsx` | 店舗リスト（ヘッダ装飾・オートフィルタ・ウィンドウ枠固定） |
| `fetch_log.csv` | 取得ログ（全URLのstatus/リダイレクト/バイト数/所要時間） |
| `failed_companies.csv` | 取得できなかった会社・ロケーター一覧＋理由 |
| `run_summary.md` | サマリ（件数・会社別内訳・適用した品質ルール） |
| `run.log` | 実行ログ |

### 出力カラム（仕様の15項目）

会社名 / 店舗名 / 都道府県 / 住所 / 店舗URL / 問い合わせフォームURL / 代表電話番号 /
店舗電話番号 / お問い合わせメールアドレス / 店舗数（会社全体）/ 本部URL / 採用ページURL /
Google口コミ件数 / Google評価 / 備考

## 品質ルール（コードに実装済み）

- **HTTP200確認**: 全URLを実際にGETし、最終ステータス200のもののみ採用。店舗URL/フォームURLは
  備考に「HTTP200確認」を明記。生存しないフォームURLは空欄化（リンク切れ禁止）。
- **公式サイト限定**: シードは各社公式ドメインのみ。別ホストへのリダイレクトは備考に記録。
- **店舗専用フォーム優先**: 店舗ページ内の問い合わせ系リンクを優先採用。同一ホストを優先し、
  無い場合のみ会社フォームにフォールバック。検出できなければ空欄。
- **重複排除**: (店舗URL正規化) → (会社+住所) → (会社+店舗名+都道府県) の順で1件に統合。
- **品質ゲート**: 店舗名 と (住所 または 店舗URL) が揃わない行は出力しない。
- **推測しない**: 取得できない項目は空欄のまま。件数合わせの捏造をしない。
- **礼儀**: robots.txt尊重、ホスト毎に最小間隔（既定1.5秒）、リトライは指数バックオフ。

## 取得方式（正確性のため）

店舗詳細ページからの抽出は **JSON-LD（schema.org `RealEstateAgent` / `LocalBusiness`）を最優先**。
多くの不動産サイトが店舗名・住所・電話・URLを構造化データで持つため、CSSセレクタ依存より堅牢です。
JSON-LDで欠けた項目のみ、保守的なヒューリスティクス（日本の電話番号正規表現、`mailto:`のみ採用、
問い合わせ系アンカー検出）で補完します。

## Googleクチコミ件数・評価について

Google口コミ件数/評価は **Google Places API（要APIキー）** が無いと正確に取れません。
本パイプラインは捏造を避けるため、APIキーが無い場合は空欄にします。取得する場合は
`GOOGLE_MAPS_API_KEY` を設定のうえ Places API 連携を有効化してください（拡張ポイントを
`extract.py` にコメントで明示）。

## 対象会社（`seeds.json`）

アパマンショップ / エイブル / ミニミニ / ピタットハウス / ハウスコム / タウンハウジング /
アエラスグループ / リブマックス / ルームピア(ROOMPIA) / CLCコーポレーション

SUUMO掲載店舗の追加収集口（会社ページ→店舗一覧）も `seeds.json` の `suumo_company_index` に
用意（利用規約・robotsを遵守して低レートで）。

## 注意・既知の制約

- 一部サイトは店舗一覧をJavaScriptで描画します。その場合は静的HTMLにリンクが出ないため、
  `store_detail_url_regex` の調整、もしくはヘッドレスブラウザ（Playwright）連携が必要です。
  検出0件のロケーターは `failed_companies.csv` に理由付きで記録されます。
- `store_detail_url_regex` は検索で確認した実URLパターンに基づきますが、サイト改修で
  変わり得ます。最初の実行ログ（locator行の検出件数）で要確認。
